## About the Project

This project is a collection of modern AI Interface UI templates developed using HTML, CSS, and JavaScript.

The interfaces demonstrate common interaction patterns used in AI-powered applications such as chat assistants, command bars, and natural-language search systems.

The project focuses on clean UI design, simple interactions, responsive layouts, and beginner-friendly implementation using plain web technologies.

---

## Implemented UIs

### 1. AI Assistant

The AI Assistant provides a conversational interface where users can interact with an AI-style assistant.

Users can:

- Send messages
- Receive predefined AI responses
- Use suggested prompts
- Start a new conversation
- Open recent conversations
- Switch between light and dark mode

Location:

```text
Root project
index.html
style.css
script.js
```

---

### 2. AI Chat

The AI Chat interface provides a modern chat experience between the user and an AI assistant.

Features include:

- User and AI message bubbles
- Send button
- Enter key support
- Typing indicator
- Suggested prompts
- Dynamic demo responses
- Recent conversations
- New Chat button
- Light and Dark mode
- Responsive layout

---

### 3. AI Chat Sidebar

The AI Chat Sidebar pattern provides navigation for conversations while keeping the main chat area visible.

The sidebar contains:

- AI Chat title
- New Chat button
- Recent Chats
- Conversation selection
- Theme switching

This layout is useful for AI applications where users need to manage multiple conversations.

---

### 4. AI Command Bar

The AI Command Bar provides a quick way for users to enter commands or questions and receive an AI-style response.

Features include:

- Command input
- Run button
- Ctrl + K interface indicator
- Quick suggestion buttons
- Predefined AI responses
- Enter key support
- Thinking state
- Responsive design

Location:

## GitHub Collaboration Workflow

The project follows the GitHub collaboration workflow required for the hackathon:

1. Fork the repository
2. Clone the repository
3. Create a feature branch
4. Develop the assigned UI
5. Commit the changes
6. Push the feature branch
7. Create a Pull Request
8. Review the Pull Request
9. Make changes if required
10. Merge the Pull Request

Each team member develops their assigned UI patterns separately and contributes them to the common repository.
